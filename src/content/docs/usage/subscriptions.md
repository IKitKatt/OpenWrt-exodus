Профиль — это конфиг Mihomo: подписка (скачивается по URL) или загруженный файл. При каждом запуске профиль объединяется с настройками Exodus и mixin-файлом, результат — профиль запуска.

## Поля подписки

| Поле | Что задаёт |
| --- | --- |
| Название | заменяется названием от провайдера (`profile-title`), если он его присылает |
| URL | ссылка подписки |
| URL информации | только если трафик и срок действия отдаёт другой адрес |
| User-Agent | по умолчанию `Mihomo/Exodus v{version}`, `{version}` заменяется версией Exodus |
| Интервал обновления, часов | пусто — интервал провайдера (`profile-update-interval`), иначе каждый час; `0` — только кнопкой «Обновить» |
| Отправлять HWID | заголовки [HWID](#hwid), по умолчанию включено |

- Сохранённый файл подписки используется, пока не прошёл её интервал: запуск не ждёт провайдера.
- Работающее ядро получает изменённую подписку без перезапуска (на OpenWrt — перезагрузкой сервиса), соединения и выбранные прокси сохраняются. Подписка, не прошедшая проверку, не применяется.
- **Полное обновление** удаляет всё, что скачали провайдеры правил и прокси текущего профиля, скачивает подписку заново и перезапускает сервис. Файлы локальных провайдеров сохраняются.

## Заголовки провайдера

| Заголовок | Что показывает Exodus |
| --- | --- |
| `profile-title` | название подписки |
| `announce` | блок с анонсом на странице статуса |
| `profile-logo` | логотип рядом с подпиской и в анонсе |
| `support-url` | кнопка «Поддержка» |
| `subscription-userinfo` | трафик и срок действия |
| `profile-update-interval` | интервал обновления, если он не задан вручную |

## HWID

Панели с лимитом устройств (например, Remnawave) отличают роутер от других устройств по заголовкам `x-hwid`, `x-device-os`, `x-ver-os` и `x-device-model`. Exodus отправляет их по умолчанию, для подписки, которой они не нужны, выключите «Отправлять HWID».

`x-hwid` собирается из модели и MAC роутера и не меняется после переустановки или сброса настроек. Его можно задать вручную, остальные заголовки читаются из прошивки. Где посмотреть значения: «Настройки» → «Сервис» → HWID на Keenetic и Asus, «Расширенные» → «Настройки прокси» → «Прочее» на OpenWrt.

## Mixin-файл

Свои настройки Mihomo поверх профиля: DNS-серверы, hosts, сниффер, провайдеры правил, листенеры и всё остальное. Файл объединяется с профилем при каждом запуске, настройки Exodus важнее. Правится на странице «Редактор».

На OpenWrt mixin-файл применяется, только если включено «Расширенные» → «Опции mixin» → «Содержимое файла mixin».

Ключи `nikki-proxies`, `nikki-proxy-groups` и `nikki-rules` добавляют прокси, группы и правила **в начало** списков профиля:

```yaml
nikki-proxies:
  - name: PROXY
    type: ss
    server: proxy.example.com
    port: 443
    cipher: chacha20-ietf-poly1305
    password: password
nikki-proxy-groups:
  - name: PROXY_GROUP
    type: select
    proxies:
      - PROXY
nikki-rules:
  - DOMAIN,direct.example.com,DIRECT
  - DOMAIN-SUFFIX,proxy.example.com,PROXY
```

Для простых правил удобнее редактор правил: «Настройки» → [«Правила»](/usage/settings/#правила) на Keenetic и Asus, «Расширенные» → «Опции mixin» → «Правила» на OpenWrt. Справочник параметров — [документация Mihomo](https://wiki.metacubex.one/).
